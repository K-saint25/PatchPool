# Contributing to PatchPool

Thank you for your interest in PatchPool.

The project is currently defining its initial requirements and architecture.
Before submitting implementation pull requests, please open or join a GitHub
Discussion so the change can be aligned with the current design.

## Pull requests

- Keep each pull request focused on one change.
- Link the relevant issue or discussion.
- Include tests or verification steps when behavior changes.
- Never commit API keys, access tokens, Codex credentials, or personal data.
- Disclose material use of AI assistance in the pull request description.

By contributing, you agree that your contribution is licensed under the Apache
License 2.0.
